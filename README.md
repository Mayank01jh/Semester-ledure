# Semester Ledger

A self-contained academic management ledger and degree progression tracker designed for B.Tech CSE.

## Features
- **Multi-Semester Architecture**: Full tracking across Semesters 1 through 8.
- **Attendance Tracker**: Course-by-course present/absent counts, safe skips, recovery projections, and attendance simulation.
- **Subject & Curriculum Editor**: Rename subjects, update course codes, credits, and weekly class frequency.
- **Exam Schedule & Editor**: End-term exam dates, countdown days, and attendance readiness indicators with inline editing.
- **Backlog & CGPA Planner**: Target grade calculators, clearance effects, and 8-semester cumulative CGPA roadmap.
- **Reappear Fee Calculator**: Cost estimation for reappear papers.
- **Pure Black & White Aesthetic**: Stark high-contrast monochrome design with 1-click Light / Dark theme toggle.
- **Passcode & Login Vault**: Built-in master passcode protection to lock your academic ledger, with 1-click lock, session memory, passcode change modal, and secure salted hashing.
- **Local Persistence**: All data is stored directly in browser `localStorage`.

## Getting Started
Open `Semester Ledger.html` directly in any modern web browser or serve locally:
```powershell
python -m http.server 8000
```
Then navigate to `http://localhost:8000/Semester%20Ledger.html`.
